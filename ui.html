Turn wireframes into editable Figma layers with AI, or import JSON manually. Both workflows reuse the components, styles, and tokens in the current file whenever possible.

Wireframe ASCII → Figma

Convert a Markdown or ASCII wireframe into JSON and import it directly. AI reuses the components, styles, and tokens available in the current Figma file.

The current Figma component and token catalog is included automatically. Your key is not saved in the document or plugin storage.

Import existing JSON when you want full control of the structure. You can also export the catalog or selected layer as reference data.

A selected file is imported first. If no file is selected, the pasted JSON is imported.
